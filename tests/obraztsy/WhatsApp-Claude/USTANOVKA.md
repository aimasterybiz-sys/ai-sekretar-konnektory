# Установка коннектора WhatsApp — инструкция для Claude

Человек не программист. Все команды запускаешь ты сам; человеку пишешь коротко и простыми словами, только когда
нужно его действие (кнопка в окне, пароль, телефон). Термины «терминал», «pip», «MCP» человеку не называй.
Перед каждым шагом проверь, не сделан ли он уже, — тогда пропусти. После шага — одна строка итога.

Папка коннектора: на Mac `~/WhatsApp-Claude`, на Windows `%USERPROFILE%\WhatsApp-Claude`.
Ниже `ПАПКА` — эта папка. `PY` — команда Python: на Mac `python3`, на Windows `python` (или `py -3`).

## 1. Python
Проверь `PY --version` — нужна 3.10 или новее.
Нет или старее:
- **Windows** — `winget install -e --id Python.Python.3.13 --scope user --accept-source-agreements --accept-package-agreements`.
  Дальше в этой же сессии используй полный путь `%LOCALAPPDATA%\Programs\Python\Python313\python.exe`
  (в Git Bash: `"$LOCALAPPDATA/Programs/Python/Python313/python.exe"`). Нет winget — попроси открыть Microsoft Store,
  найти «Python 3.13», нажать «Получить» и написать «готово».
- **Mac** — `curl -L -o ~/Downloads/python.pkg https://www.python.org/ftp/python/3.13.9/python-3.13.9-macos11.pkg`,
  затем `open ~/Downloads/python.pkg`. Скажи: «Открылся установщик Python: нажимайте „Продолжить", потом
  „Установить", введите пароль от Mac. Когда появится „Установка завершена" — напишите „готово"».
  После этого `python3` — это `/usr/local/bin/python3`.

## 2. Библиотеки
`PY -m pip install -r ПАПКА/SKRIPTY/requirements.txt`. Ругается на «externally managed» — добавь `--user`.
Ошибка сертификатов на Mac — запусти `"/Applications/Python 3.13/Install Certificates.command"` и повтори.

## 3. Программа WhatsApp (wacli)
`PY ПАПКА/SKRIPTY/wa_ustanovka.py` — сам выберет файл под систему и проверит его.
Скажет «macOS слишком старая» — честно скажи человеку, что на этом Mac коннектор не заработает (нужна macOS 12+), и остановись.

## 4. Вход в WhatsApp
Скажи: «Возьмите телефон: WhatsApp → Настройки → Связанные устройства → Привязка устройства. Сейчас откроется
картинка с квадратным кодом — наведите на неё камеру телефона».
Запусти `PY ПАПКА/SKRIPTY/wa.py vhod` с таймаутом 10 минут. Код обновляется сам, картинка открывается сама.
Не получилось (камера не видит код, телефон пишет ошибку) — спроси номер телефона и запусти
`PY ПАПКА/SKRIPTY/wa.py vhod --telefon +<номер>`: появятся 8 знаков; скажи ввести их на телефоне в том же меню,
внизу «Привязать по номеру телефона».
Телефон пишет, что устройств слишком много — попроси отвязать одно старое в «Связанных устройствах» и повтори.

## 5. Фоновая служба
`PY ПАПКА/SKRIPTY/wa.py sluzhba` — каждые 10 минут подтягивает новую переписку, работает и после перезагрузки.

## 6. Подключить к Claude
`PY ПАПКА/SKRIPTY/mcp_podklyuchit.py`.

## 7. Проверка и финал
`PY ПАПКА/SKRIPTY/wa.py doctor` — должно быть «Вход в WhatsApp: есть» и «Служба: включена».
Потом скажи человеку ровно это:
«Готово. Теперь полностью закройте Claude (Mac: Cmd + Q; Windows: правой кнопкой по значку Claude возле часов →
Выйти) и откройте снова. Потом вставьте второй промпт со страницы инструкции».

## Если человек попросит удалить коннектор
1. `PY ПАПКА/SKRIPTY/mcp_podklyuchit.py --ubrat`
2. `PY ПАПКА/SKRIPTY/wa.py sluzhba --stop`
3. Отвязать устройство: `ПАПКА/SKRIPTY/bin/wacli --store ПАПКА/NASTROYKI/wacli auth logout`
   (на Windows `wacli.exe`).
4. Удалить папку `ПАПКА` целиком. Скажи: «Коннектор удалён, вся переписка с компьютера стёрта. В телефоне ничего не изменилось».
