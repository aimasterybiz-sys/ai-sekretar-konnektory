# Почта: подключить, показать, отключить

Человек ничего не делает в терминале и не вводит пароли в чат — всё через страницу «Подключение почты» в браузере. Команды ниже: на Mac `python3`, на Windows `python` (если открывается Microsoft Store — `py`). Запускай из папки секретаря.

## Подключить почту
1. Проверь библиотеки: `python3 -c "import keyring, msal, msal_extensions"`. Ошибка — поставь сам: `python3 -m pip install -r SKRIPTY/requirements.txt` (pip ругается на «externally managed» — добавь `--user`).
2. Скажи человеку: «Сейчас в браузере откроется страница „Подключение почты". Выберите вашу почту и впишите адрес — страница сама покажет, где взять пароль, и проверит вход. Подключить можно сколько угодно ящиков подряд. В конце нажмите „Готово"».
3. Запусти `python3 SKRIPTY/pochta.py dobavit` **в фоне** и дождись, когда он завершится сам (кнопка «Готово» или 15 минут без действий). Если человек пишет, что страница не открылась, — покажи ему адрес из вывода команды (строка «откройте этот адрес»).
4. Покажи итог: `python3 SKRIPTY/pochta.py --spisok`. У ящика «только чтение» — скажи: «Читать письма секретарь будет, а отправлять с этого ящика — нет», и запусти `python3 SKRIPTY/pochta.py doctor`, чтобы показать причину.
5. Спроси один раз: «Есть адреса, письма от которых и к которым секретарь не должен хранить даже у себя на компьютере (банк, врач, личное)?» Адреса или домены (`@bank.lv`) — по одному в строке в `NASTROYKI/pochta-isklyuchit.txt`.
6. Предложи: «Собрать письма с понедельника сейчас?» Да — `python3 SKRIPTY/pochta.py` и одна строка итога по каждому ящику.

Если человек прислал пароль в чат — не используй его. Скажи: «Пароль лучше не писать в чат. Откройте страницу подключения — там он сохранится безопасно. Этот пароль приложения после подключения можно удалить в настройках почты и создать новый».

## Outlook, Hotmail, Microsoft 365
Подключаются кнопкой «Войти через Microsoft» на той же странице — без пароля. Если на странице написано «пока не включено» — вход через Microsoft ещё не включил организатор курса (`MS_CLIENT_ID`). Скажи это человеку как есть; остальные почты подключаются уже сейчас. Рабочая почта Microsoft 365 может попросить «согласие администратора» — его даёт администратор компании, один раз.

## Какие почты подключены
`python3 SKRIPTY/pochta.py --spisok` — покажи как есть.

## Отключить ящик
Владелец назвал адрес — `python3 SKRIPTY/pochta.py udalit <адрес>`. Пароль стирается с компьютера, собранные письма остаются.

## Почта не собирается
`python3 SKRIPTY/pochta.py doctor` — покажи результат и что делать по каждой строке с ✗. Типичное: сменили пароль от Google — пароли приложений сбрасываются, ящик подключают заново через страницу (пункт «Подключить почту»).

## Чего не делаешь
Не открываешь и не показываешь `NASTROYKI/pochta.json`, `ms-token.bin`, `.env` и пароли. Не подключаешь почту командами в обход страницы. Письма отправляешь только через `skill-publikatsiya`.
