# Коннекторы AI-секретаря

WhatsApp, Telegram и почта для AI-секретаря курса Protuz «Нейросети для бизнеса: эра AI-агентов». Работают на Mac и Windows внутри Claude (вкладка Code).

## Для учеников

Откройте Claude → вкладка Code → папка `02_sekretar` → новый чат. Внизу чата нажмите «Авто» и выберите Manual — в нём Claude спрашивает разрешение перед каждым действием (в «Авто» Claude сам блокирует скачивание обновления). Затем вставьте:

```
Обнови коннекторы секретаря. Скачай https://github.com/aimasterybiz-sys/ai-sekretar-konnektory/releases/latest/download/konnektory.zip во временную папку, распакуй и запусти оттуда obnovit.py с таймаутом 10 минут, передав ему путь к этой папке секретаря. Если на компьютере нет Python — поставь его сам. Покажи мне итог как есть.
```

Проверить всё сразу: «Проверь коннекторы».

Claude пишет, что действие заблокировано или отклонено (режим «Авто»)? Внизу чата переключите режим с «Авто» на ручной, где Claude спрашивает перед действиями, и отправьте фразу ещё раз.

## Что внутри

| Папка | Что это |
|---|---|
| `obnovlenie/` | `obnovit.py` — одно обновление всего; `pravki.py` — исправления; `proverka.py` — «Проверь коннекторы» |
| `whatsapp-claude/` | коннектор «WhatsApp в Claude» (программа [wacli](https://github.com/openclaw/wacli), MIT) |
| `pochta-konnektor/` | почта: Gmail, iCloud, ukr.net, свой домен и другие — сколько угодно ящиков (Outlook и Microsoft 365 — позже); установщик в папку секретаря |
| `tests/` | автотесты; на каждый выпуск они проходят на чистых Windows, Mac и Linux |

## Правила безопасности

- Во вкладке Code перед каждой отправкой сообщения или письма Claude спрашивает человека «Разрешить?» — в любом режиме, включая «Авто». Отправляйте сообщения из вкладки Code.
- Пароли почты — в хранилище системы (Связка ключей Mac, Диспетчер учётных данных Windows), не в файлах.
- Письма и сообщения читаются без отметки «прочитано»; ничего не удаляется.

## Выпуск

`python sborka.py` → `dist/konnektory.zip`, `dist/WhatsApp-Claude.zip`, `dist/pochta-konnektor.zip` → выпуск на GitHub. После публикации workflow «Проверка выпуска» скачивает архив как ученик и запускает обновление на Windows и Mac.
